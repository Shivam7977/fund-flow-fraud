The Problem

A transaction is only one piece of the story.

A suspicious transaction rarely looks suspicious in isolation. The real signal can emerge from when it happened, how an account behaves, where the money moves, and how multiple transactions connect.

01 — Transaction

What happened?

  • Amount
  • Transaction type
  • Time
  • Balance movement
  • Account profile
02 — Behavior

Is this normal for the account?

  • Transaction velocity
  • Historical activity
  • Transaction volume
  • Sender / receiver behavior
  • Profile mismatch
03 — Network

Where did the money go?

  • Connected accounts
  • Fund movement
  • Circular flows
  • Fan-in / fan-out
  • Suspicious relationships

Follow the Money

Fraud doesn't always move straight.

Suspicious activity can reveal itself through the shape of money movement between accounts.

Severity: High
Round-Trip

Money leaves. Money comes back.

A → B → C → A

Short circular transaction paths where funds return to the originating account.

Severity: High
Fan-Out

One account. Many destinations.

A → B A → C A → D

A single account distributing funds across many recipients.

Severity: High
Fan-In

Many sources. One destination.

A → Z B → Z C → Z

Multiple accounts concentrating funds into one potential mule account.

Severity: High
Structuring

Just below the threshold.

₹47,500 ₹45,000 ₹48,250

Repeated transactions within a defined amount range.

Context Matters

The transaction has a history.

A ₹50,000 transaction means something different when an account normally moves ₹2,000. Fund Flow uses historical and batch-level context to understand activity relative to account behavior.

Account History

Know what came before.

Previous transaction counts and total volume associated with each account.

Transaction Velocity

Detect unusual activity.

Behavioral changes across transaction activity, not isolated evaluation.

Balance Intelligence

Follow the numbers.

Compare transaction amounts with balances and detect inconsistencies.

Profile Mismatch

Behavior vs. account profile.

Surface transactions that don't align with expected account characteristics.
